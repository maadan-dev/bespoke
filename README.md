# Bespoke by Yeni — Luxury Bridal & Couture Website

Official website for **Bespoke by Yeni** (*"…creating elegant outfits you deserve."*) featuring a **Noir, Off-White, and Gold** editorial aesthetic inspired by Alonuko and Veekee James.

## ✨ Key Features
- **Noir, Off-White & Gold Luxury Theme**: Alternating deep Noir (`#0E0C0A`) and warm Bridal Ivory (`#FAF6F0`) sections accented with metallic Gold (`#D4AF37`) stitch borders matching the official brand emblem.
- **Animated Editorial Hero Slider**: Showcases real brides in custom gowns with smooth Ken Burns zoom transitions and the official **Bespoke by Yeni** seal.
- **Filterable Real Brides Lookbook & Fullscreen Lightbox**: High-resolution gallery of all 8 bridal portraits with category filtering (*White Wedding Gowns*, *Civil & Reception Looks*, *Close-Up Details*) and one-click *"Inquire About This Look"* pre-fill.
- **Interactive Bridal Wardrobe Estimator**: Allows prospective brides to toggle the services they need (Wedding Dress, Traditional, Civil, Reception, Bridesmaids, Aso Ebi, Consultation), adjust group piece counts, see their starting investment + 60% deposit in Naira (`₦`), and transfer their selection directly into the inquiry form.
- **Alonuko-Inspired Consultation Selector & WhatsApp/Email Concierge**: Interactive appointment category cards, wedding date lead-time advisor, and instant formatted inquiry dispatch to WhatsApp (`+2347034460677`) or Email (`bespokebyyeni@gmail.com`).

## 🚀 Quick Deployment (Zero Build Step Required)
Because this is a pure, ultra-fast static HTML/CSS/JS site, you can deploy it anywhere in under a minute:
1. **Vercel / Netlify / Cloudflare Pages**: Push this repository to GitHub and import it with zero build configuration (`Output Directory: .`).
2. **GitHub Pages**: Enable GitHub Pages on the `main` branch root.
3. **Custom Domain (`bespokebyyeni.com` / `.ng`)**: Point your domain's DNS (`A` or `CNAME` record) to your Vercel/Netlify/GitHub Pages host.
